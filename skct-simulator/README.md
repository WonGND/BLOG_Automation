# SKCT 리허설

SK그룹 종합역량검사(SKCT)의 **심층역량검사**와 **인지역량검사**를 실제 형식으로
연습하는 웹 도구다. 빌드 도구·서버·의존성이 없는 정적 페이지이므로
`index.html`을 그대로 열면 동작한다. 홈 상단 탭으로 두 검사를 오간다.

---

# 1. 심층역량검사

## 무엇을 하는가

한 문항군에 문장 세 개가 나온다. 각 문장에 ①~⑤로 답한 뒤, 그중 나와 **가장 가까운 것**과
**가장 먼 것**을 하나씩 고른다. 실제 심층역량검사와 같은 응답 방식이다.

제출하면 두 가지가 나온다.

1. **12개 역량 프로파일** — 백분위 막대(높은 순 정렬)와 12축 레이더
2. **신뢰도 3지표** — 과장응답 위험 · 응답 일관성 · 응답 균형

심층역량검사는 점수를 올리는 시험이 아니라 걸러지지 않는 것이 목표인 검사라서,
역량 점수보다 신뢰도 지표가 먼저 읽히도록 화면을 구성했다.

## 검사 세트 5종

| 코드 | 이름 | 문항군 | 문장 | 시간 | 성격 |
|---|---|---|---|---|---|
| SET A | 실전 모의 A형 | 34 | 102 | 15분 | 12역량 전 영역 표준형 |
| SET B | 실전 모의 B형 | 34 | 102 | 15분 | A형과 문항이 전혀 겹치지 않는 재응시용 |
| SET C | 10분 속성 진단 | 18 | 54 | 8분 | 시험 직전 컨디션 점검 |
| SET D | 핵심역량 집중 (VWBE·패기) | 24 | 72 | 11분 | 자발성·성취·패기·협업·리더십·성실 |
| SET E | 압박·신뢰도 집중 | 26 | 78 | 10분 | 과장응답 문항 12개 전부 + 가장 빠듯한 시간 |

## 측정 역량

성실·책임(RESP), 주도·자발(INIT), 성취·목표지향(ACHV), 패기·끈기(GRIT),
협업·팀워크(COOP), 소통·공감(COMM), 리더십·영향력(LEAD), 도전·혁신(INNO),
분석·문제해결(ANLY), 정서안정·스트레스내성(STAB), 적응·유연성(ADPT), 규범·윤리(ETHC)

## 채점 방식

- **문항 응답** — 정채점 문항은 응답값 그대로, 역채점 문항은 `6 - 응답값`으로 환산한다.
- **가깝다/멀다 보정** — 해당 역량 평균에 문항당 ±0.55를 반영한다.
- **백분위** — 원점수를 평균 3.35 / 표준편차 0.55의 정규분포로 환산한다.
  실제 SK 규준이 아니라 연습용 시뮬레이션 규준이다.
- **과장응답 위험** — "한 번도 ~한 적이 없다" 류 문항 12개의 동의 정도.
  35 미만 양호 / 35–62 주의 / 62 초과 경고.
- **응답 일관성** — 표현만 바꾼 유사 문항 쌍(역량당 최대 2쌍)의 응답 차이.
  80 이상 양호 / 66–79 주의 / 66 미만 경고.
- **응답 균형** — ①⑤ 극단 쏠림과 ③ 중앙 쏠림에 대한 감점.
  75 이상 양호 / 55–74 주의 / 55 미만 경고.

## 결과 데이터

결과 화면에서 두 가지 형식으로 내보낼 수 있다.

- **JSON** — 역량별 원점수·환산점수·백분위, 신뢰도 지표 원값, 문항별 응답 원자료 전체
- **CSV** — 문항별 응답 표 + 역량 요약 표 + 지표 표 (UTF-8 BOM 포함, 엑셀에서 바로 열린다)

응시 기록은 브라우저 `localStorage`에만 남는다. 서버로 전송되는 데이터는 없다.
두 검사의 기록은 각각 따로 쌓인다.

## 검사 중 오류에 대한 대비

응시 도중 흔히 생기는 사고를 화면에서 막거나 복구할 수 있게 처리했다.

| 상황 | 동작 |
|---|---|
| 실수로 새로고침·탭 닫기 | 이탈 경고를 띄운다. 진행 상황은 이미 저장돼 있어 되돌아오면 이어서 응시할 수 있다 |
| 브라우저 뒤로가기 | 사이트를 벗어나지 않고 홈으로 돌아간다. 진행 상황은 저장된다 |
| 제출 버튼·Enter 연타 | 중복 제출을 막아 결과가 두 번 쌓이지 않는다 |
| 버튼에 포커스가 있을 때 Enter | 버튼이 처리하도록 넘겨, 문항군이 두 칸씩 넘어가지 않는다 |
| 세 문장을 다 답한 뒤 숫자 키 | 무시한다. 마지막 응답을 덮어쓰지 않는다 |
| 같은 문장을 가깝다/멀다에 동시 지정 | 먼저 지정된 쪽이 해제된다 |
| 사생활 보호 모드 (localStorage 차단) | 검사는 정상 진행되고, 기록을 남길 수 없다는 안내를 띄운다 |
| 저장 공간 부족 | 오래된 기록의 원자료부터 정리하고 다시 저장한다. 그래도 실패하면 알린다 |
| 문항 은행·세트 정의 변경 | 예전 세션은 이어받지 않는다 (`bankVersion` 불일치) |
| 채점 중 예외 | 응답을 유지한 채 타이머를 되살리고 다시 제출할 수 있게 한다 |
| 응답이 하나도 없는 제출 | 차트 대신 안내를 보여 준다 |
| 탭을 오래 닫아 둔 경우 | 경과 시간은 저장 시점까지만 누적되므로 타이머가 튀지 않는다 |

응답할 때 화면을 통째로 다시 그리지 않고 해당 버튼만 갱신하기 때문에,
클릭·키 입력 후에도 포커스가 유지되고 화면이 깜빡이지 않는다.

## 조작

| 키 | 동작 |
|---|---|
| `1`~`5` | 문장 응답 (A → B → C 순서로 채워진다) |
| `A` `S` `D` | 가장 가깝다 |
| `Z` `X` `C` | 가장 멀다 |
| `Enter` / `→` | 다음 문항군 (마지막이면 제출) |
| `←` | 이전 문항군 |

제한 시간이 끝나면 자동 제출되고, 남은 문항은 미응답으로 채점된다.
중간에 나가도 진행 상황이 저장되어 이어서 응시할 수 있다.

## 실행과 배포

```bash
# 그대로 열기
open index.html

# 로컬 서버
npx serve .

# 단일 파일로 빌드 → dist/index.html, dist/artifact.html
node build.mjs
```

GitHub Pages는 `.github/workflows/pages.yml`이 처리한다. `main`의 `skct-simulator/`가
바뀌면 워크플로가 돌면서 `actions/configure-pages`의 `enablement` 옵션으로 저장소의
Pages를 켜고 이 폴더를 사이트 루트로 배포한다. Settings에서 따로 만질 것은 없다.

`dist/index.html`은 CSS·JS가 모두 인라인된 단일 파일이라 어디에든 그대로 올릴 수 있다.

## 구성

```
skct-simulator/
├── index.html          진입점
├── assets/
│   ├── style.css       디자인 토큰 + 레이아웃 (라이트·다크)
│   ├── bank.js         문항 은행 204문장, 12역량, 세트 5종 정의
│   └── app.js          검사지 조립 · 응시 화면 · 채점 · 결과 · 내보내기
├── assets/
│   ├── cog-exams/
│   │   └── exam1~5.js      회차별 문항 60개 + 지문·자료 6개
│   ├── cognitive-bank.js   회차 파일을 합쳐 은행·세트를 조립
│   └── cognitive.js        인지역량 응시·일시정지·채점·결과
├── build.mjs           단일 파일 빌드
└── dist/               빌드 산출물
```

`app.js`가 셸(상단바·테마·토스트·라우팅·저장소)을 만들고 `window.SKCT`로 노출하면,
`cognitive.js`가 그것을 받아 `cog-*` 화면을 그린다. 두 검사가 같은 페이지·같은
디자인 토큰을 쓰면서 코드는 분리돼 있다.

타이포그래피는 표제 **Gothic A1**, 본문 **Noto Sans KR**, 수치·라벨 **IBM Plex Mono**의
세 역할로 나눴다. 본문은 16px / 행간 1.72이고, 한국어가 어절 중간에서 끊기지 않도록
`word-break: keep-all`을 적용했다.

문항군은 세트별 고정 시드(`SKCT_SETS[].seed`)로 조립하므로, 같은 세트는 몇 번을 열어도
같은 문항이 같은 순서로 나온다. 한 문항군 안에는 서로 다른 역량의 문장만 들어간다.

# 2. 인지역량검사

정답이 있는 검사다. 채점되고, **모든 문항에 해설이 붙는다.**

## 영역과 세트

**실전 모의고사 5회분 + 영역별 집중 3종**, 총 **300문항**이다.

| 코드 | 이름 | 문항 | 시간 | 성격 |
|---|---|---|---|---|
| 1회 | 실전 모의고사 1회 | 60 | 62분 | 표준 난도. 처음이면 여기서 시작 |
| 2회 | 실전 모의고사 2회 | 60 | 62분 | 논지 약화, %p와 % 구분 등 함정 한 겹 추가 |
| 3회 | 실전 모의고사 3회 | 60 | 62분 | 원탁 배치, 계차수열 등 형태가 꺾인 문항 |
| 4회 | 실전 모의고사 4회 | 60 | 62분 | 이차식 최적화, 세 집합, 이중 피동 — 난도 최고 |
| 5회 | 실전 모의고사 5회 | 60 | 62분 | 왕복 평균 속력, 복리 증가율, 최소 교집합 |
| 언어 | 언어이해 집중 | 20 | 20분 | 다섯 회차에서 겹치지 않게 4문항씩 |
| 수리 | 수리 집중 | 20 | 22분 | 다섯 회차에서 겹치지 않게 4문항씩 |
| 추리 | 추리 집중 | 20 | 20분 | 다섯 회차에서 겹치지 않게 4문항씩 |

각 회차는 **1교시 언어(20문항/20분) → 2교시 수리(20문항/22분) → 3교시 추리(20문항/20분)**로
진행되며, **남은 시간은 다음 교시로 넘어가지 않는다.** 교시 사이에는 준비 화면이 들어간다.

### 출제 범위 (회차당)

- **언어이해 20** — 유의어·반의어·어휘관계(4), 어법·띄어쓰기·호응(2), 속담·한자성어(1),
  빈칸추론·문장배열·접속어(3), 지문 독해 2편(7: 주제·일치·추론·논지약화·적용),
  논리오류(1), 명제추론(1), 중의성(1)
- **수리 20** — 응용계산 14(방정식·부등식·농도·일률·거리속도·원가할인·경우의 수·확률·
  집합·평균·비율·나이·도형·수열·최적화 등), 자료해석 6(표 2종)
- **추리 20** — 명제·대우·삼단논법·연쇄(4), 조건추리 3문항 세트(3), 순서·배치추리(2),
  참·거짓(2), 수·문자 규칙(3), 도식추리 2문항 세트(2), 대응규칙(1), 어휘추리(1), 집합추리(1)

자료는 지문 19편과 표 11개이며, 각 회차의 자료는 그 회차 문항만 참조한다.

## 시간 멈추기

응시 중 언제든 **일시정지**할 수 있다 — 상단바 버튼이나 키보드 `P`.

- 타이머가 멈추고 문제가 가려진다 (멈춰 놓고 훔쳐보는 것을 막는다)
- 멈춘 시간은 **총 소요 시간과 문항별 소요 시간 어디에도 포함되지 않는다**
- 정지 상태는 저장되므로, 새로고침하거나 나갔다 돌아와도 멈춘 지점 그대로 이어진다
- 나가기·뒤로가기·탭 닫기로 이탈해도 자동으로 정지 상태로 저장된다

실전 감각을 볼 때는 멈추지 않고 끝까지, 복습할 때는 자유롭게 멈춰 가며 푸는 식으로 쓰면 된다.

## 채점과 결과

- **총점** — 정답 수, 정답률, 추정 백분위(정답률 평균 58% / 표준편차 17%p 규준)
- **영역별 정답률** — 소요 시간과 문항당 평균 시간 포함
- **유형군별 정답률** — 어휘·어법, 독해·문맥, 언어추론, 응용계산, 자료해석,
  명제·논리, 조건·순서추리, 규칙·도식 8개 군. 낮은 순으로 정렬되어 약점이 먼저 보인다
- **오답 노트** — 틀린 문항마다 지문·표, 선택지(내 답과 정답 표시), 해설
- **교시별 시간**과 **시간을 많이 쓴 문항 상위 6개**
- JSON·CSV 내보내기

## 조작 (인지역량)

| 키 | 동작 |
|---|---|
| `1`~`5` | 선택지 고르기 |
| `←` `→` | 이전 / 다음 문항 |
| `F` | 나중에 다시 볼 문항으로 표시 |
| `P` | 일시정지 / 계속 |
| `Enter` | 다음 문항 (마지막이면 교시 마치기) |

문항 이동 그리드에서 응답한 문항과 표시한 문항이 한눈에 보이고, 아무 문항으로나 건너뛸 수 있다.

## 문항 검수

문항을 눈으로만 보고 넘기지 않고 기계로 검증했다.

**계산 재검증** — 수리 100문항 전부를 문항과 무관한 별도 코드로 다시 풀어
정답칸의 값과 대조했다. 방정식은 완전탐색, 확률·경우의 수는 전수 열거로 확인했다.

**논리 퍼즐 유일해 검증** — 조건추리·배치·순서·참거짓·매칭 문항은 모든 배치를
완전탐색해 **조건을 만족하는 해가 정확히 하나뿐임**을 확인했다. 이 과정에서
3회 원탁 문항의 선택지 두 개가 동시에 참이 되는 오류를 발견해 고쳤다.

**'옳은 것을 고르시오' 유형** — 다섯 선택지의 참·거짓을 모두 계산해
참인 것이 정확히 하나인지 확인했다.

**구조 검사** — 선택지 5개·중복 없음, 정답 인덱스 범위, 자료 참조 유효성,
회차 간 자료 교차 참조 없음, 발문+선택지 완전 중복 없음, 해설이 존재하지 않는
보기 번호를 인용하지 않는지까지 자동으로 점검한다.

**정답 위치 균형** — 처음 만들었을 때 정답이 ③에 300문항 중 105개(35%)로 몰려 있었다.
그대로 두면 "③ 찍기"를 학습하게 되므로, 수리 21문항의 선택지 값을 다시 잡고
순서에 의미가 없는 76문항의 선택지를 회전시켜 **①~⑤ 각각 정확히 60문항**으로 맞췄다.
회전할 때 해설이 인용하는 보기 번호도 함께 옮겼고, 값·연도·요일·알파벳처럼
순서가 의미를 갖는 선택지는 건드리지 않았다. 조정 뒤 정답 **내용**이 그대로인지
174건을 다시 대조했다.

**전 구간 실행 검증** — 헤드리스 브라우저로 8개 세트를 정답키대로 끝까지 풀어
전부 만점이 나오는지, 한 칸씩 밀어 찍으면 0점이 나오는지 확인한다.

## 고지

문항과 규준은 공개된 검사 형식을 참고해 자체 제작한 **연습용**이며 SKCT 기출이 아니다.
백분위는 시뮬레이션 규준으로 환산한 값이라 실제 응시자 집단 대비 순위가 아니다.
결과는 응답 습관을 점검하는 용도로만 쓰는 것이 맞다.
