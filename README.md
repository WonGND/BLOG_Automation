# BLOG_Automation

## 프로젝트

- **[skct-simulator](skct-simulator/)** — SKCT(SK그룹 종합역량검사) 연습용 웹 시뮬레이터.
  - **심층역량검사** — 검사 세트 5종, 문항 은행 204문장, 12역량 프로파일과 신뢰도 3지표 리포트
  - **인지역량검사** — 기술사무직 5영역(언어이해·자료해석·창의수리·언어추리·수열추리)
    실전 모의고사 5회분(회차당 100문항) + 영역별 집중 5종, 총 500문항.
    전 문항 해설, 일시정지 가능한 타이머, 오답 노트
  - 출제 유형은 SKCT 기술사무직 구성만 담는다 — 언어이해 9유형, 자료해석 4유형(모두 고르시오·그래프 분석 포함),
    창의수리 9유형, 언어추리 7유형, 수열추리 1유형
  - **개념 및 치트키 정리** — 인지역량 화면 맨 위. 13개 유형마다 개념 · 치트키(빨리 푸는 법) ·
    예시 풀이 · 예상문제(즉시 채점·해설)를 붙였다. 치트키 54개, 예상문제 27문항
  - **응시 도구** — 실제 시험처럼 메모장 · 그림판 · 계산기를 응시 화면에 올렸다. 옮길 수 있는 창이고,
    메모와 그림은 문항을 넘겨도 남는다
  - 결과 JSON·CSV 내보내기. 의존성 없는 정적 페이지라 `skct-simulator/index.html`을 그대로 열면 동작한다.
