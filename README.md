# BLOG_Automation

## 프로젝트

- **[skct-simulator](skct-simulator/)** — SKCT(SK그룹 종합역량검사) 연습용 웹 시뮬레이터.
  - **심층역량검사** — 검사 세트 5종, 문항 은행 204문장, 12역량 프로파일과 신뢰도 3지표 리포트
  - **인지역량검사** — 언어·수리·추리 60문항, 세트 5종, 전 문항 해설, 일시정지 가능한 타이머
  - 결과 JSON·CSV 내보내기. 의존성 없는 정적 페이지라 `skct-simulator/index.html`을 그대로 열면 동작한다.
