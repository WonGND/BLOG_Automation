# 생활정보 블로그 원고 생성기

한국어 생활정보 블로그용 **주제 추천 + 본문 원고**를 만들어 주는 웹사이트입니다.
결과는 네이버 블로그 에디터에 그대로 붙여넣을 수 있는 **마크다운 없는 순수 텍스트**예요.

브라우저에서 주제를 고르고 버튼 하나만 누르면 됩니다. 프롬프트를 매번 복사해 붙여넣을 필요가 없어요.

---

## 빠른 시작

```bash
npm install
cp .env.example .env      # .env 를 열어 ANTHROPIC_API_KEY 를 채워주세요
npm start
```

브라우저에서 http://localhost:3000 을 열면 됩니다.

API 키는 https://console.anthropic.com 에서 발급받아요.
키는 서버에서만 쓰이고 브라우저로는 절대 전달되지 않습니다.

---

## 사용 흐름

**1단계 · 주제 추천**
범주(씨앗 키워드)를 넣거나 비워둔 채로 실행하면 주제 후보 5개가 나옵니다.
비워두면 기준 날짜에 맞는 계절·시기성 주제를 뽑아요. 5개 중 1개는 추천으로 표시되고 추천 이유도 함께 나옵니다.

**2단계 · 원고 작성**
후보 카드의 "이 주제로 원고 쓰기"를 누르면 주제가 자동으로 넘어갑니다. 직접 입력해도 됩니다.

- **시리즈 회차**를 2 이상으로 두면 이전 편 요약 입력칸이 열려요. 내용이 겹치지 않게 쓰고, 도입부에서 이전 편을 한 문장으로 언급합니다.
- **제휴·광고 체크박스**를 켜면 본문 첫 줄에 대가성 표시 문구가 들어갑니다.
- 결과 화면에서 제목 / 본문 / 태그를 각각 복사하거나 `.txt`로 내려받을 수 있어요.
- 생성한 원고는 `output/` 폴더에 `.json`과 `.txt`로 자동 저장되고, 화면 아래 "최근 생성한 원고"에서 바로 다음 편을 이어 쓸 수 있습니다.

## 결과 검사 (자동)

원고를 받으면 서버가 프롬프트 규칙에 맞는지 먼저 확인합니다.

| 검사 | 처리 |
| --- | --- |
| 마크다운 기호(`#` `*` `-` `\|` 불릿 등) 사용 | ❌ 자동 재작성 |
| 분량 1,500~2,200자(공백 포함) 벗어남 | ❌ 자동 재작성 |
| 마지막이 질문형으로 끝나지 않음 | ❌ 자동 재작성 |
| 제휴 모드인데 첫 줄에 대가성 표시 없음 | ❌ 자동 재작성 |
| 소제목 개수가 3~4개 + 마무리 구성에서 벗어남 | ⚠️ 경고만 표시 |
| 본문에 금액·퍼센트 등 수치 표현 | ⚠️ 경고 (검증 가능한 값인지 확인용) |
| 썸네일 문구 길이 초과 | ⚠️ 경고 |
| 모델이 보고한 `char_count`가 실제와 다름 | 실제 값으로 자동 교정 |

❌ 항목이 남으면 서버가 위반 내용을 알려주며 다시 쓰게 합니다(기본 1회, `MAX_REPAIR`로 조절).
⚠️ 항목은 결과 화면 상단에 노란 박스로 표시되고, 발행 전에 사람이 판단하면 됩니다.

`verify_required`(엔진이 확신하지 못한 수치·날짜·요금·법령)는 본문에서 빠지고 사이드바에 따로 모입니다. 발행 전에 확인해 주세요.

## 설정 (.env)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | **필수.** Anthropic API 키 |
| `PORT` | `3000` | 서버 포트 |
| `MODEL` | `claude-opus-5` | 사용할 모델 |
| `EFFORT_SUGGEST` | `medium` | 주제 추천 추론 강도 (`low`~`max`) |
| `EFFORT_WRITE` | `high` | 원고 작성 추론 강도 |
| `MAX_REPAIR` | `1` | 규칙 위반 시 자동 재작성 횟수 (최대 3) |
| `SAVE_OUTPUT` | `true` | 결과를 `output/`에 저장할지 여부 |

## 구조

```
prompts/system.ko.txt   프롬프트 원문. 이 파일이 엔진의 규칙 전부입니다.
server/engine.js        Claude 호출 + 자동 재작성 루프
server/schema.js        출력 JSON 스키마 (Structured Outputs)
server/validate.js      규칙 검사기
server/index.js         Express 서버 + API
public/                 화면 (별도 빌드 없음)
test/smoke.js           가짜 API로 파이프라인 전체 점검
```

**문체나 규칙을 바꾸고 싶다면 `prompts/system.ko.txt`만 고치면 됩니다.**
이 파일은 통째로 시스템 프롬프트로 들어가고, 회차마다 바뀌는 값(주제, 회차, 이전 편 요약 등)만
사용자 메시지로 전달합니다. 덕분에 프롬프트 캐시가 계속 맞아 두 번째 호출부터 비용이 줄어들어요.

출력은 JSON 스키마로 고정되어 있어서 인사말·설명·코드펜스가 섞일 수 없습니다.

## API

파이프라인에서 직접 부르고 싶을 때 씁니다.

```bash
curl -X POST http://localhost:3000/api/suggest \
  -H 'Content-Type: application/json' \
  -d '{"seed":"여름 전기요금","today":"2026-08-23"}'

curl -X POST http://localhost:3000/api/write \
  -H 'Content-Type: application/json' \
  -d '{"topic":"여름철 실내 온도 관리","seriesIndex":2,"prevSummary":"1편에서는 선풍기를 다뤘어요","affiliate":false}'
```

응답에는 프롬프트가 정의한 JSON(`result`)과 함께 검사 결과(`issues`), 통계(`stats`),
생성 횟수(`attempts`), 토큰 사용량(`usage`)이 들어 있습니다.

`GET /api/health` 로 키 설정 여부를, `GET /api/history` 로 최근 생성 목록을 확인할 수 있어요.
